# FocusBoard – Task Management Dashboard
A responsive task management dashboard built with React and JavaScript to organize tasks, monitor progress, and improve daily productivity.

## Live Demo

**Website:** https://focusboard-2026.netlify.app/

**GitHub:** https://github.com/RosanFaraMazwinM/focusboard

## Features

- Create, edit, and delete tasks.
- Search tasks by title.
- Filter tasks by status and priority.
- Update task status.
- Dynamic dashboard statistics.
- Focus Notes carousel.
- Persistent task storage using localStorage.
- Responsive desktop, tablet, and mobile layouts.

## Technologies

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Lucide React
- Browser localStorage

## Getting Started

Clone the repository:

```bash
git clone https://github.com/RosanFaraMazwinM/focusboard.git
```

Navigate into the project:

```bash
cd focusboard
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## Data Storage

Task information is stored locally in the browser using localStorage. No backend service is required.
